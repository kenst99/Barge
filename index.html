Đội tàuThu gọn / mở
Cự ly đo dọc tim luồng trên bản đồ, sai số khoảng 5–10%. Thời gian = cự ly ÷ tốc độ, chưa tính chờ con nước, neo đậu, qua trạm. Tuyến có đoạn biển chỉ dành cho sà lan đủ cấp đăng kiểm.
Giờ nước lớn / nước ròng xem trên thegioimoicau.com theo trạm tham chiếu gần nhất. Càng vào sâu trong sông, con nước tới trễ hơn và yếu hơn trạm ven biển; đầu nguồn (Vĩnh Xương, Tân Châu) mùa lũ gần như không còn con nước. Nhận định rong/kém tính theo tuổi trăng, có thể lệch ±1 ngày.
Nhận vị trí tự động
Ứng dụng hỏi máy chủ theo chu kỳ và di chuyển sà lan trên bản đồ. Dùng Google Apps Script (mẫu ở cuối) hoặc API của đơn vị lắp định vị.
Dùng các chỗ trống {barge} {lat} {lon} {spd} {hdg} {ts} {status}. Để trống nếu API chỉ cho đọc.
Nếu API trả về mã thiết bị (IMEI, ID máy định vị) khác tên tàu, nhập mã đó vào đây. Để trống thì dùng số hiệu sà lan.
Điện thoại trên tàu gửi vị trí
Mở ứng dụng này trên điện thoại của tài công, chọn sà lan rồi bấm bắt đầu. Máy sẽ gửi GPS lên máy chủ theo chu kỳ. Cần giữ màn hình sáng và mở trang bằng https.
Mẫu máy chủ Google Apps Script
  1. Tạo một Google Sheet mới, vào Tiện ích mở rộng → Apps Script.
  2. Xoá hết code cũ, dán đoạn code bên dưới, bấm Lưu.
  3. Triển khai → Tùy chọn triển khai mới → Ứng dụng web. Thực thi dưới tên: Tôi. Người có quyền truy cập: Bất kỳ ai.
  4. Chép URL kết thúc bằng /exec dán vào ô Địa chỉ API ở trên.
